# 💫 About Me:
Software Development Engineer at **Verint** (MachEye), working on LLM-powered product features, RAG/NLQ systems (Neo4j, OpenSearch), and backend microservices. <br>
B.Tech in Information Technology from **NIT Karnataka, Surathkal** (2021–2025). <br>
Previously founding engineer at **Kalppo** (formerly Mentara), an AI-driven adaptive learning & mentorship platform. <br>
Author of 2 IEEE publications on NLP-based clinical QA systems and software reliability prediction. <br>
